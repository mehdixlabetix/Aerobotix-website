The challenge

A new game every season

Read the field. Own the match.

Eurobot introduces an original theme and actions every year. The robot must understand the arena through sensors, execute a strategy without human control, and remain dependable when the match begins.

The real opponent is uncertainty. A strong design has to survive imperfect positioning, physical contact, timing pressure, and the difference between a clean workshop test and a live arena.

The system

One robot, many disciplines

Every subsystem. One purpose.

Competition performance comes from integration: the mechanism, electronics, code, and match strategy must behave as one coherent machine.

MODULE / 01

Mechanics

Designing compact, robust mechanisms that execute the season's actions accurately and repeatedly.

MODULE / 02

Embedded

Connecting actuators, sensors, power, and real-time control into a dependable electrical architecture.

MODULE / 03

Autonomy

Localizing, planning, and adapting so the robot can make every decision after the start signal.

MODULE / 04

Strategy

Turning game rules into prioritized actions, safe paths, timing decisions, and resilient match plans.
